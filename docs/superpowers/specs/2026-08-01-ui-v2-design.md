# UI Improvements V2: Scanner Animation & Button Fixes

## 1. Context and Goals
The current UI has non-functional placeholder buttons in the sidebar, a "Fit to screen" button that only resets zoom, and generic loading animations. The goal is to provide a highly immersive, futuristic AI feel through visual loading states, and to make all visible buttons fully functional or remove them.

## 2. Core Features

### 2.1 Holographic AI Scanner (Canvas Generation State)
Instead of a standard spinner, the DiagramCanvas will display a scanning effect while `isGenerating` is true.
- **Visuals:** A horizontal glowing line (laser) that animates from the top to the bottom of the canvas area repeatedly.
- **Background:** The canvas retains its dark grid background, but with a subtle pulsing glow indicating activity.

### 2.2 Breathing Text Animation (Chat Loading State)
- **Visuals:** The loading text ("Sedang berpikir...", "Menganalisis...") will use the Tailwind `animate-pulse` utility to fade in and out gently (redup-nyala). 
- **Icons:** The spinning `Loader2` icon will be removed or replaced by a static AI icon, relying purely on the pulsing text to indicate processing.

### 2.3 True "Fit to Screen" Logic
- **Behavior:** The "Fit to Screen" (Maximize) button in the toolbar will measure the actual width/height of the generated SVG and the width/height of the container. 
- **Math:** It will set the `zoom` state to `min(containerWidth / svgWidth, containerHeight / svgHeight) * 0.9` (leaving a 10% margin).

### 2.4 Cleanup of Non-Functional Elements
- **Sidebar:** The dummy links ("Settings", "GitHub", "About") at the bottom of the `Sidebar` component will be completely removed to prevent user confusion.

## 3. Component Architecture
- **ChatPanel:** Update `isGenerating` conditionally rendered block to apply `animate-pulse` to the text span and simplify the icon.
- **DiagramCanvas:** 
  - Add a new conditional block for `isRendering` (or `isGenerating`) to render the CSS-based scanning laser.
  - Create a CSS animation in `index.css` or use arbitrary Tailwind values (`animate-[scan_2s_linear_infinite]`).
  - Update `handleReset` to calculate the SVG DOM rects and set `zoom`.
- **Sidebar:** Remove the `<div>` containing the 3 placeholder anchor tags.

## 4. Error Handling
- The Fit to Screen calculation must gracefully fallback to `zoom = 1` if the SVG DOM node cannot be measured or has 0 width/height.
